# Jeremy Zoerman — personal website mockup

Open `dist/index.html` in a browser, or serve the folder locally:

```sh
cd personal-site/dist
python3 -m http.server 8080
```

Then visit http://localhost:8080.

This buildless mockup includes a home page, interests index, four topic pages,
a musings index, three sample essays, and an Elsewhere page. All sample essays
are labeled. Contact details and the future professional domain are placeholders.

Edit `dist/style.css` for styling and the HTML files for content. The SVG
illustration is local. Google Fonts are optional; system fonts provide fallbacks.
No dependencies or build step are required.

Verification: all local HTML links and assets resolve. Browser visual QA has not
been performed. Sites registration succeeded; publication was blocked by DNS
resolution of the source repository host. The saved Site identity is retained in
`.openai/hosting.json` for a future publication attempt.
